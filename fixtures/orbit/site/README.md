# Orbit

A small static task board. No build step.

## Run

    npm run dev

Then open http://localhost:4180/

## Demo account

- Email: demo@orbit.test
- Password: orbit-pass

## Product promises

- Fully keyboard accessible: every action can be completed without a mouse.
- Dark mode is supported and remembered.
- Works down to 900px wide without horizontal scrolling.
- Every list has a helpful empty state that tells you what to do next.
- Respects the reduced-motion preference.

## Pages

- `index.html` - sign in
- `board.html` - the board (Board / List / Calendar views), new task dialog, filters, export
- `activity.html` - recent activity and comments
- `settings.html` - profile, appearance, danger zone
